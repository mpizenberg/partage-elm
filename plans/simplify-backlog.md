# Simplification backlog

- **The vendored service-worker generator only routes by path prefix:** a static `/` beside an SPA cannot be excluded exactly without making every app route network-only, so `build-sw.mjs` inserts one asserted exact-root branch. Add exact-path strategies upstream and delete the insertion when service-worker routing is next touched.
- **Summary durability failures:** Ordinary active-group summary saves publish optimistic workspace/catalog state but ignore IndexedDB failure, so memory can remain ahead of durable state until reload. Define one rollback, retry, or visible-failure policy without weakening the serialized mutation queue.
- **First imported group persistence:** Compressed-file import bypasses `requestPersistOnFirstGroup` even though the helper's contract says create, import, and join should ask the browser to protect the origin after the first group. Route successful import through the same policy.
- **Repeated small utilities:** filename sanitization, `allJust`, localized month/date labels, other calendar helpers, and several view helpers have duplicate implementations. Absorb them when an owning module is already being changed; a miscellaneous-utils module would merely relocate complexity. `monthName` now has a third would-be consumer: the changelog page falls back to ISO dates rather than adding a copy, and both existing copies hardcode English word order around the month name.
- **`entryDetail` still takes nine positional arguments:** `Page.Group.EntriesTab.entryDetail` kept the long parameter list its callers shed when `entryCardView`/`groupedByDate` moved to `CardEnv`. Fold it into the same record the next time that function is touched.
- **Invite key lives in the URL:** `Route` carries the join secret in the fragment and `handleJoinRoute` reads it back from `model.route`, so the key reaches browser history, synced tab lists, screen shares, and any page-URL reporter (the feedback button is suppressed on that route for exactly this). Moving the secret into `Page.JoinGroup` and stripping the fragment on load is contained — `Route.elm` plus three lines in `Main.elm` — but regresses reload on a join link; it needs its own plan document.
- **`processGroupOutputs` repeats the same unwrap-and-persist shape:** four of its branches open `Ready readyData`, edit one field, and two of them then queue an `Infra.Storage` save through the runner. A helper taking `(InitData -> InitData)` plus an optional save task would absorb `UpdateGroupSummary`, `RemoveGroup`, `SaveSelfProfile`, and `RequestFeedback` into one line each. Do it the next time a fifth output joins them.
- **Expected relay interruption policy is repeated:** `Page.Group` spells `Server.isNetworkError err || Server.isFrozen err` at sync, relay creation, and compaction. Put the policy next to `Infra.Server.Error` when another expected-silent state or a fourth call site appears; until then a helper would not materially reduce code.
- **Relay container runs as root:** add `USER node` to `packages/relay/Dockerfile` once the dokku `/data` volume mount is verified writable by that uid (`storage:ensure-directory` chowns the host directory to a different one).
- **The `copy-button` overlay is inlined six times across five files:** `Page.Move`, `Page.ErrorLog`, `Page.Group.MembersTab` (twice), `EntriesTab` and `BalanceTab` each build the same `Html.node "copy-button"` with the same four inline styles, because a custom element is outside elm-ui's reach. One `UI.Components.copyOverlay` — or a single `copy-button { … }` rule in `public/index.html`, where the date-input normalization already lives — would delete twenty-four style lines and the temptation to write CSS in a view.
- **No single text-input primitive:** `UI.Components.formTextField` wraps a handful of fields while some twenty other `Ui.Input.text` call sites are raw, and every one of them relies on inheriting `Theme.font.md` to stay at the 16px below which iOS Safari zooms a focused field. One input element owning its own font size would make that constraint unbreakable; fold call sites into it as their pages are touched.
- **`ConcurrentTask.Http` error bodies are not values:** `BadStatus` carries the `body` field exactly as the JS runtime produced it — `null` for a request that expected no body, an unparsed JSON *string* otherwise — so any classifier that decodes it as an object silently never fires. `Server.isReadOnlyResponse` did for the life of the read-only feature, and its unit test passed by hand-building a shape the runtime cannot produce. Status codes are the only part of a refusal the app can currently read; if a future error needs more, the request's `Expect` has to change with it.
- **"Migrate" now names two unrelated flows:** the deployment move (`/migrate`, `homeMigration*`, `move*`, `receive*`) and the tamper response that rebuilds one group under a new key (`/groups/:id/migrate`, `migrate*`). The URL space collides too. Rename one of them the next time either is worked on.
- **Build-time placeholders have no shared definition:** `__CANONICAL_ORIGIN__`, `__FEEDBACK_PROJECT_ID__`, and `__CONFIG_DIGEST__` are each spelled as a bare literal in the script that emits them and again in `packages/relay/src/node-server.js` that substitutes them, and `public/marketing.js` now spells a third copy to recognise an unsubstituted build. A typo in any one of them fails silently as a placeholder served to users. One exported map, imported by both sides, when a fourth placeholder appears.
